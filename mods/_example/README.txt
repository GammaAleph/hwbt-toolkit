Example mod layout. Folders whose name starts with "_" are NOT installed.
To use a mod, copy this folder and remove the "_" from its name.

  NAME.OGG / NAME.ARC / ...    - replaces the whole archive file (same name, see "hwbt list")
  TEXT0000.txt                 - texts (create with: hwbt lda2txt TEXT0000.LDA)
  16ANGELS_LOD0_GRA.ARC\       - a folder named like the bank...
     16AngelsBodyDA.png        - ...with the edited textures (same names as exported)

Пример структуры мода. Папки, имя которых начинается с "_", не устанавливаются.
Чтобы использовать мод, скопируйте эту папку и уберите "_" из её имени.
