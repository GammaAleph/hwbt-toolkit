# HWBT Toolkit — моддинг Hot Wheels: Beat That! (PC)

[English version](README.md)

HWBT Toolkit распаковывает и упаковывает архивы игры, переводит текстуры в PNG/TGA/DDS и обратно, конвертирует шрифты, конвертирует
тексты и устанавливает моды с автоматическим откатом. Через него же можно установить патчи сообщества
**Beat That! Revival V1 и V2**. Интерфейс на русском и английском.

Hot Wheels: Beat That! разработала Eutechnyx (2007), издала Activision. Игра работает на собственном движке Eutechnyx.

## Установка

1. Скачайте `HWBT-Toolkit-v1.2.3.zip` со страницы [Releases](https://github.com/GammaAleph/hwbt-toolkit/releases)
   и распакуйте его в любую папку.
2. Запустите `hwbt.exe`. Язык переключается в верхней части окна.

Нужен .NET Framework 4.5 или новее. Он уже встроен в Windows 8, 10 и 11.

## Возможности

| Кнопка                       | Что делает                                                       |
|------------------------------|------------------------------------------------------------------|
| Установить / удалить моды    | ставит все отмеченные моды из `mods\` в `Data\` и `lData\`; неотмеченные удаляются |
| Вернуть оригинал             | возвращает оба архива байт-в-байт                                |
| Распаковать архив…           | извлекает все 2141 файл игры                                     |
| Распаковать и декомпилировать… | извлекает всё и распаковывает содержимое файлов: текстуры → PNG/TGA, шрифты → PNG/TXT, тексты → TXT, звуки → WAV, речь и музыка → OGG, прочие записи `.ARC` → `.bin` + `index.txt` |
| Текстуры ARC → PNG/TGA…      | экспортирует текстуры выбранных банков `.ARC` в `<БАНК.ARC>\`     |
| Шрифты ARC → PNG/TXT…        | экспортирует шрифты выбранных банков `.ARC` в `<БАНК.ARC>\<имя>.font\` |
| Звуки HDR → WAV/OGG…         | экспортирует выбранные звуковые (`.wav`) и речевые (`.ogg`) банки в `<БАНК>.HDR\` |
| Тексты LDA → TXT…            | переводит таблицы строк в редактируемый текст                    |
| ☐ Конвертировать все текстуры в PNG | текстуры, которые в игре называются `*.tga`, экспортируются в TGA, если флажок не стоит |
| Установить патч V1 / V2      | скачивает патч автора (с проверкой SHA-256) и запускает его установщик |
| Удалить патч                 | запускает скрипт отката автора для установленного патча          |

### Как сделать мод: шаблон

Каждая подпапка `mods\` — отдельный мод. Папки, имя которых начинается с `_`, не устанавливаются. Программа
держит пустой **`mods\_template\`** с частями `Data\` и `lData\`, устроенный в точности как результат
**«Распаковать и декомпилировать»**. Скопируйте его, переименуйте копию и положите туда изменённые файлы:

```
mods\МойМод\
  Data\                                    <- высокая детализация (...\Hot Wheels\Data)
    arc\<БАНК.ARC>\textures\<имя>.png      текстуры (.png / .tga / .dds)
    arc\<БАНК.ARC>\fonts\<имя>.font\       шрифты (font.txt и/или atlas.png)
    texts\TEXTxxyy.txt                     тексты
    sounds\<БАНК>\<имя>.wav                звуки
    speech\<БАНК>\<имя>.ogg                комментатор
    music\<ТРЕК>.OGG                       музыка
    files\<ИМЯ>                            любой файл архива целиком
  lData\                                   <- низкая детализация (...\Hot Wheels\lData), то же самое
  <всё, что вне Data\ и lData\>            <- ставится в обе
```

Раз структура совпадает с распаковкой, можно копировать оттуда **папки целиком**, хоть весь `Data\decompiled\` и
`Data\files\`. Файлы, совпадающие с игрой, распознаются и пропускаются, ставится только то, что вы изменили.
В журнале будет строка `N file(s)/bank(s) identical to the original game data - skipped`.

### Чем отличаются Data и lData

У игры две копии данных. Часть мода вне `Data\`/`lData\` ставится в обе. Полное сравнение PC-версии:

| Файлы | Data и lData |
|---|---|
| 288 из 1820 банков `.ARC` | **разные**: низкодетальные модели и текстуры с другими именами, размерами и форматами |
| 17 звуковых банков уровней (`ZONE*.HDR/.RAW`) | **разные**: другие звуки и частоты |
| музыка `.OGG`, комментатор `.SPD` | звук одинаковый (отличаются только служебные номера потоков Ogg) |
| тексты, шейдеры, видео, звуки моторов | полностью одинаковые |

Например, в `lData\BRUTALISTIC_LOD0_GRA.ARC` кузов называется `Brutalistic-body-D` (DXT3), а в `Data` —
`Brutalistic-body-DA` (A4R4G4B4). Поэтому текстурам, моделям и звукам уровней нужна своя версия в `lData\`, а
тексты и музыку можно класть прямо в папку мода. Если картинки не подходят к банку, журнал покажет, какие текстуры
в нём на самом деле есть. Какую детализацию использует игра, выбирается в `DisplayConfig.exe`.

### Короткая раскладка (тоже работает)

| Что положить в папку мода                     | Что произойдёт                                     |
|-----------------------------------------------|----------------------------------------------------|
| `ИМЯ.EXT` (любой файл из архива)              | файл заменяется целиком: `TITLE.OGG`, `CAR.ARC`, … |
| `TEXT0000.txt`                                | компилируется в `TEXT0000.LDA`                     |
| папка `ИМЯ.ARC\` с `*.png` `*.tga` `*.dds` (в любых подпапках) | текстуры вставляются в оригинальный банк |
| папка `ИМЯ.ARC\ШРИФТ.font\` (`font.txt` и/или `atlas.png`) | пересобирается шрифт (глифы, интервалы, атлас) |
| папка `ШРИФТ.font\` вне папки банка           | шрифт пересобирается **во всех** банках, где он есть |
| папка `ИМЯ.HDR\` с `*.wav`                    | пересобирается звуковой банк (`ИМЯ.HDR` + `ИМЯ.RAW`) |
| папка `ИМЯ.HDR\` с `*.ogg`                    | пересобирается банк речи (`ИМЯ.HDR` + `ИМЯ.SPD`)   |

PNG и TGA сжимаются в формат оригинальной текстуры (DXT1/DXT3/A4R4G4B4…) с тем же числом мипмапов, поэтому размер
банка не меняется. `.dds` записывается как есть: так можно выбрать другой формат. Лишние `.wav`/`.ogg`, которых нет
в банке, добавляются как новые звуки или фразы, но игра проиграет их, только если что-то на них ссылается.
Форматы описаны в [docs/FORMATS.ru.md](docs/FORMATS.ru.md).

### Шрифты

Шрифты меню и HUD — растровые, они лежат в `*_FONTSARCHIVE.ARC` и `GLOBALMENUASSETS*.ARC`. «Распаковать и
декомпилировать» (или кнопка «Шрифты ARC → PNG/TXT…») выкладывает каждый шрифт папкой `<имя>.font\`:

* `atlas.png` — картинка со всеми символами. Их можно перерисовать, передвинуть или добавить новые.
* `font.txt` — по строке на глиф: код(ы) символа, прямоугольник в атласе, ширина и сдвиг. Там же строки `kern`
  с исключениями для отдельных пар.

Скопируйте папку в `mods\ВашМод\A_MAINMENU_FONTSARCHIVE.ARC\mainmenu.font\`, отредактируйте и установите.
* Без `font.txt` заменяется только атлас.
* Без атласа меняются только метрики.
* Если вы увеличили атлас, не меняя раскладку, оставьте строку `atlassize` как есть — координаты пересчитаются сами.
* Папка `<имя>.font\`, лежащая прямо в моде (не внутри папки `<БАНК.ARC>\`), применяется **ко всем банкам, где
  есть шрифт с таким именем**. Например, `mods\МойШрифт\mainmenu.font\` меняет все 14 копий `mainmenu`.

Коды символов — это байты 8-битных текстовых таблиц, поэтому новым глифам можно назначать свободные коды 0x80–0xFF.

### Текстуры высокого разрешения

Каждая текстура хранит свой размер, поэтому в принципе игра принимает и бо́льшие. Но есть жёсткие ограничения:

* **16 МБ на одну текстуру**: поле размера в банке занимает 24 бита. Влезают DXT1 4096×4096, DXT3/DXT5 4096×2048
  и несжатая 2048×1024. Программа откажется ставить текстуру больше.
* `HOT.exe` — 32-битная программа **без флага Large Address Aware**, ей доступно только 2 ГБ памяти. Большие
  текстуры держите сжатыми (PNG/TGA сжимаются автоматически).
* В движке могут быть буферы загрузки фиксированного размера. Сначала проверьте одну машину с увеличенной
  текстурой (например, 2048×1024), а уже потом идите дальше.
* Сохраняйте пропорции: координаты текстур (UV) относительные.

Программа предупреждает о текстурах больше 2048, о записях, которые намного больше оригинала, и о сильно
выросших банках.
Список консольных команд выводит `hwbt help`; он также есть в [английском README](README.md#command-line).

## Как скомпилировать

Visual Studio не нужна: используется компилятор C#, встроенный в Windows (.NET Framework 4.x).

```bat
git clone https://github.com/GammaAleph/hwbt-toolkit.git
cd hwbt-toolkit
build.bat
```

`build.bat` вызывает `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe` и собирает все файлы `src\*.cs`
в `hwbt.exe`. То же самое вручную:

```bat
csc /nologo /optimize+ /target:exe /out:hwbt.exe /win32manifest:src\app.manifest ^
    /r:System.Windows.Forms.dll /r:System.Drawing.dll ^
    /r:System.IO.Compression.dll /r:System.IO.Compression.FileSystem.dll src\*.cs
```

Код написан на C# 5, поэтому собирается и в Visual Studio или MSBuild (target `net48`).

## Проверено и ограничения

* Пересборка `Data` и `lData` без изменений даёт архивы, идентичные оригиналу байт-в-байт.
* Все 50 таблиц строк и все 10 534 текстуры проходят цикл «экспорт → импорт» без единого отличия.
* Повторное сжатие всех текстур игры из PNG/TGA: несжатые форматы без потерь, у DXT в среднем 49 дБ (DXT1) и
  59 дБ (DXT3) PSNR, размер всегда совпадает с оригиналом.
* Все 59 звуковых и речевых банков собираются обратно из `.wav`/`.ogg` байт-в-байт.
* Патч V2 устанавливается на английский `HOT.exe` и проходит проверку своего установщика.
* Патч V1 скачивается и проходит проверку хеша, но его установщик в тестах не запускался: ему нужны права администратора.
* **В самой игре моды пока не проверялись**: в среде разработки нет Direct3D 9. Буду рад отзывам.
* В таблицах `lda0` используется кодировка Windows-1252, кириллицы в них нет. Модели, физику и скрипты в `.ARC`
  можно заменять только целыми файлами. Архив не должен превышать 2 ГБ.
