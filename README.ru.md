# HWBT Toolkit — моддинг Hot Wheels: Beat That! (PC)

[English version](README.md)

HWBT Toolkit распаковывает и упаковывает архивы игры, переводит текстуры в PNG/DDS и обратно, конвертирует
тексты и устанавливает моды с автоматическим откатом. Через него же можно установить патчи сообщества
**Beat That! Revival V1 и V2**. Интерфейс на русском и английском.

Hot Wheels: Beat That! разработала Eutechnyx (2007), издала Activision. Игра работает на собственном движке Eutechnyx.

## Установка

1. Скачайте `HWBT-Toolkit-v1.0.zip` со страницы [Releases](https://github.com/GammaAleph/hwbt-toolkit/releases)
   и распакуйте его в любую папку.
2. Запустите `hwbt.exe`. Язык переключается в верхней части окна.

Нужен .NET Framework 4.5 или новее. Он уже встроен в Windows 8, 10 и 11.

## Возможности

| Кнопка                       | Что делает                                                       |
|------------------------------|------------------------------------------------------------------|
| Установить моды              | ставит все отмеченные моды из `mods\` в `Data\` и `lData\`       |
| Вернуть оригинал             | возвращает оба архива байт-в-байт                                |
| Распаковать архив…           | извлекает все 2141 файл игры                                     |
| Текстуры ARC → PNG/DDS…      | экспортирует текстуры из банков `.ARC`                           |
| Тексты LDA → TXT…            | переводит таблицы строк в редактируемый текст                    |
| Установить патч V1 / V2      | скачивает патч автора (с проверкой SHA-256) и запускает его установщик |
| Удалить патч                 | запускает скрипт отката автора для установленного патча          |

### Структура мода

Каждая подпапка `mods\` — отдельный мод. Папки, имя которых начинается с `_`, не устанавливаются.

| Что положить в папку мода           | Что произойдёт                                     |
|-------------------------------------|----------------------------------------------------|
| `ИМЯ.EXT` (любой файл из архива)    | файл заменяется целиком: `TITLE.OGG`, `CAR.ARC`, … |
| `TEXT0000.txt`                      | компилируется в `TEXT0000.LDA`                     |
| папка `ИМЯ.ARC\` с `*.png`/`*.dds`  | текстуры вставляются в оригинальный банк           |

Пример: `mods\BlueCar\16ANGELS_LOD0_GRA.ARC\16AngelsBodyDA.png`. Форматы описаны в [docs/FORMATS.md](docs/FORMATS.md).
Список консольных команд выводит `hwbt help`; он также есть в [английском README](README.md#command-line).

## Как скомпилировать

Visual Studio не нужна: используется компилятор C#, встроенный в Windows (.NET Framework 4.x).

```bat
git clone https://github.com/GammaAleph/hwbt-toolkit.git
cd hwbt-toolkit
build.bat
```

`build.bat` вызывает `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe` и собирает все файлы `src\*.cs`
в `hwbt.exe`. То же самое вручную:

```bat
csc /nologo /optimize+ /target:exe /out:hwbt.exe /win32manifest:src\app.manifest ^
    /r:System.Windows.Forms.dll /r:System.Drawing.dll ^
    /r:System.IO.Compression.dll /r:System.IO.Compression.FileSystem.dll src\*.cs
```

Код написан на C# 5, поэтому собирается и в Visual Studio или MSBuild (target `net48`).

## Проверено и ограничения

* Пересборка `Data` и `lData` без изменений даёт архивы, идентичные оригиналу байт-в-байт.
* Все 50 таблиц строк и все 10 534 текстуры проходят цикл «экспорт → импорт» без единого отличия.
* Патч V2 устанавливается на английский `HOT.exe` и проходит проверку своего установщика.
* Патч V1 скачивается и проходит проверку хеша, но его установщик в тестах не запускался: ему нужны права администратора.
* **В самой игре моды пока не проверялись**: в среде разработки нет Direct3D 9. Буду рад отзывам.
* В таблицах `lda0` используется кодировка Windows-1252, кириллицы в них нет. Модели, физику и скрипты в `.ARC`
  можно заменять только целыми файлами. Архив не должен превышать 2 ГБ.
