Community Patches V1 and V2 by Kyubikkumasuta (Beat That! Revival)
Official website: https://hot-wheels-beat-that-revival.com/

EN: Click "Install Patch V1" or "Install Patch V2" in HWBT Toolkit. The patch is downloaded into this
    folder from the author's official link, verified (SHA-256) and installed with the author's own
    installer. Patch V2 already contains all V1 fixes. You can also unzip the official ZIPs here manually.

RU: Нажмите "Установить патч V1" или "Установить патч V2" в HWBT Toolkit. Патч будет скачан в эту
    папку по официальной ссылке автора, проверен (SHA-256) и установлен оригинальным установщиком
    автора. Патч V2 уже содержит все исправления V1. Можно также вручную распаковать сюда ZIP-архивы.
    Поддержите автора на официальном сайте!

The patches only change Bin\HOT.exe (V2 also adds dinput8.dll), HWBT Toolkit mods only change the data
archives - both can be used together.
